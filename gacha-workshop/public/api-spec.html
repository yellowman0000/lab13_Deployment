student_id: 1–30 English letters (A–Z/a–z), digits, underscores or hyphens. Recharge: integer 1–100000 coins. Exchange: 100–100000 coins in multiples of 100. Wallet limit: 1000000 per currency.student_id: ตัวอักษรอังกฤษ A–Z/a–z ตัวเลข ขีดล่างหรือขีดกลาง 1–30 ตัว เติม coin เป็นจำนวนเต็ม 1–100000 แลก coin 100–100000 เป็นเท่าของ 100 จำกัดยอดแต่ละสกุลไม่เกิน 1000000

Each independent draw has a 2% SSR chance. The five legendary results are equally likely within SSR: each has 0.4% overall probability. A small batch does not guarantee an SSR.แต่ละ draw มีโอกาส SSR 2% อย่างอิสระ ผล legendary ทั้งห้ามีโอกาสเท่ากันภายใน SSR จึงมีโอกาสรวมตัวละ 0.4% การสุ่มกลุ่มเล็กไม่ได้รับประกัน SSR

Proxy mappingการ map ผ่าน proxy

Direct:  http://localhost:8085/test
NPM:     http://localhost/backend/test → Express /test
API:     /backend/api/draw → Express /api/draw
Spec:    /backend/api-spec → Express /api-spec
OpenAPI: /backend/openapi.json → Express /openapi.json

NPM and app share a Docker network. The upstream is app:3000, and /backend/ is stripped before forwarding. NPM localhost refers to NPM itself.NPM และ app ใช้เครือข่าย Docker ร่วมกัน Upstream คือ app:3000 และตัด /backend/ ก่อนส่งต่อ localhost ของ NPM หมายถึง NPM เอง

Status codes and side effectsStatus code และผลต่อข้อมูล

StatusMeaningความหมาย
200Successful read or health check; empty history does not prove persistence.อ่านหรือ health สำเร็จ แต่ประวัติว่างยังพิสูจน์ persistence ไม่ได้
201Wallet operation committed; draw also saves a result.บันทึกธุรกรรมกระเป๋าแล้ว draw จะบันทึกผลสุ่มด้วย
400Invalid ID, amount, exchange multiple or JSON.ID จำนวนเงิน จำนวนเท่าของการแลก หรือ JSON ไม่ถูกต้อง
409Insufficient funds or balance limit; no operation committed.เงินไม่พอหรือเกินเพดานยอด ไม่บันทึกธุรกรรม
413JSON body exceeds 8 KB.JSON body เกิน 8 KB
503Database unavailable; inspect health and logs.ฐานข้อมูลไม่พร้อม ตรวจ health และ log
404Unknown application route.ไม่พบ route ของแอป

GET wallet initializes an empty wallet if it does not exist. History returns up to 50 newest transactions and draws. Repeated POST creates another operation; there is no idempotency key.GET wallet สร้างกระเป๋าว่างหากยังไม่มี History คืนธุรกรรมและผลสุ่มล่าสุดอย่างละไม่เกิน 50 แถว การส่ง POST ซ้ำเป็นอีกธุรกรรมหนึ่ง ยังไม่มี idempotency key

The demo has no login or account authorization. student_id is not proof of identity. Before real-user production, add authorization, abuse limits, reviewed migrations and tested backups.Demo ไม่มี login หรือสิทธิ์เข้าถึงบัญชี student_id ไม่ใช่หลักฐานยืนยันตัวตน ก่อนใช้กับผู้ใช้จริงต้องเพิ่มการตรวจสิทธิ์ จำกัดการใช้งานผิดวัตถุประสงค์ migration ที่ตรวจทาน และ backup ที่ทดสอบแล้ว
